# Feature: MCP-First Asset, 3D Department, VFX & Top-Down Map Ecosystem
Branch: `feat/system-overhaul` | Strategy: feature-branch-chain (local commits only, no push/PR)
Runner: `node --test bridge/test_asset_ecosystem.mjs` and `node bridge/test_all.mjs`

## Specs

- **S1 — Missing-asset detection & 1.2 GB Vault interconnection.** "Necesito que se mejore este sistema de De creación asistida por IA en juegos de Roblox para que siempre que no haya un asset la detecte, que falte ese asset y lo pida al usuario. Que sepa todo lo que tiene un juego, aunque normalmente ya el análisis creo que ya está en el bau que descargué estos días que pesa 1.2 GB, que también debería estar interconectado a esto haciendo un enfoque total en el MCP de Roblox Studio oficial, manteniendo una conexión mejorada con respecto a Rojo o RASEE. Vamos a pasar a hacer un enfoque más de MCP en vez de la conexión por plugin porque ya por MCP ya puedo hacer toda la IA." Connect `LihFolk Vault V2` and `LihFolk-Assets` (815 models, 204 materials, 48 skies, 9 animations, VFX) plus the project's reusable ecosystem registry; detect any missing asset before building and request it from the user instead of inventing placeholders. Check: deterministic scan against `LihFolk-Assets` CSVs and local registry, reporting missing assets accurately.
- **S2 — 3D Department: 1-by-1 Nano Banana prompts & 3-route 3D conversion.** "Necesito que haya un departamento encargado en este aspecto de generar cantidades avisales de modelos 3D, pero que primero me pida uno por uno el gemini de nano banana y dependiendo si es una IA potente la que estoy usando en ese momento o no, lo usaré en el mismo chat o en otra IA o en otro programa para pasar esos modelos a un modelo 3D listo para usar en Roblox." Queue missing 3D assets one by one with a ready-to-copy Nano Banana prompt (orthographic/3-4 view, neutral background, no baked shadows, chunky silhouette) and route conversion through Route A (in-chat Blender 5.2 parametric builder), Route B (official Studio MCP native generation), or Route C (external image-to-3D tool + Blender 5.2 auto-cleanup script enforcing <20k tris, bottom-center origin, `-Y` forward, 1 unit = 1 stud). Check: 1-by-1 prompt output and Blender normalization/validation script.
- **S3 — Fighting-game VFX Department without requiring technical user references.** "También un sistema que cree VFX bien logrados, aunque no sabría cómo pedir las referencias para algo así, como los que están en los juegos de pelea y esas activas de cosas." Provide an intent-driven VFX Recipe Catalog backed by `LihFolkVFX` / `LihFolkVFX_Abilities` and `SlimeAssetVFX` (3-value rule: white core, saturated element body, dark ink rim; 17 combat/ability presets; 9 elements; `CameraShake` and `HitStop`) so the user can select fighting-game and dopamine VFX by plain-language action without needing technical VFX references. Check: recipe catalog query and Luau module contract tests.
- **S4 — Two-stage Top-Down + Zone-Reference Map Pipeline & zero mindless decorations.** "Y mira, en el map making ya me rendí. Tengo que aprender a hacer map making porque hace unos map making muy feos, a menos de que le dé un plano por arriba." "mira tmb para el mapa le podemos dar los planos que pida los planos y despues referencias por cada zona, y que no cree decoraciones sin criterio que las cree lograda y con objetos 3d y todo, una verja modelo 3d, una maquina modelo 3d y asi" Enforce a strict two-stage map workflow: Stage 1 requests the top-down layout plan (`plano por arriba`); Stage 2 requests visual references per zone (`referencias por cada zona`) and decomposes each zone into explicit 3D prop models (`una verja modelo 3d`, `una maquina modelo 3d`, etc.). Strictly forbid mindless primitive block decorations (`decoraciones sin criterio`); every prop must resolve to a real 3D model placed with grounded raycast (`placeOnGround`), path keep-outs (`LF_NoScatter`), and `auditWorld` checks. Check: map spec validator rejecting ungrounded/primitive-only zone decorations and missing zone references.
- **S5 — Reusable Asset Ecosystem ingestion.** "y que facilmente pueda añadir mas assets al ecosistema para reutilizarlos en un futuro o usarlo de referencia, apruebo y comienza" Provide a single CLI and JSON registry (`assets/ecosystem_registry.json`) to register, tag, search, and reuse 3D models, concept references, VFX presets, and zone kits across current and future Roblox games. Check: registration, duplicate/hash validation, search, and cross-game reuse tests.
- **S6 — Modular Framework Generator, Topography + Zone References, and 10x Batching for Accessories/Mutations.** "ah y que sepa hacer frameworks a cada rato si le pido un sistema de crear nuevas cosas y asi que sepa que hacer y tal, mira no me da ni los tokens ni las chances comprobar ahorita, ahora cuando pide mapa pide la topografia y referencia de cada zona no? y cuando detecte que el modelo no sea tan detallado como accesorios o mutaciones pedira en tanda de 10 ?  y cuando sean vfxd cual sera el proceso" Provide `scaffold-framework` (`generateFrameworkBlueprint`) for 5-layer extensible Luau systems, require/support `topography` in Stage 1 of `MapZoneBuilder.luau` and `validateMapBlueprint`, and automatically batch low-detail assets (`accessory`, `mutation`, `icon`, `<= 1,000 tris`) in sets of up to 10 (`sheet_10x` 2x5 grid prompt) while keeping high-detail models 1-by-1 (`single_1x1`). Check: `batch10` prompt output, `generateFrameworkBlueprint`, and topography validation tests.
- **S7 — Choreographed 6-Phase 60 Hz Original VFX Composer, Plant/Slime Mutation Stacks, and Easy Vault Plug-and-Play on GitHub Clones.** "pero cuando es una habilidad definitiva, o el evento de una mutacion que caen meteoritos del cielo y asi los efectos de la mutacion sobre una planta y asi" "bueno el analizis que me acabas de hacer tu basicamente la animacion, es lo que tiene que hacer ahora este sistema a la hora de que le pidan un vfx original fluido y igual de detallado como lo hacen los juegos de pelea, hace esta ultima mejora, y como tal hace el commit a github, no tendran los vault o assets pero en caso de que los descarguen o los tengan se pueda incluir facil y me imagino que eso ya esta" Automatically synthesize 6-phase 60 Hz fluid animation timelines (`composeOriginalVfx` / `composeCustomStoryboard`), 4-layer surface mutations on plants/slimes (`Material` + `3D Graft in 10x batch` + `Highlight Rim` + `Ambient Particles`), and plug-and-play Vault/Asset Pack linking (`link-vault` CLI + standalone mode when the 1.2 GB pack is not present). Check: `composeOriginalVfx`, `link-vault`, and standalone fallback tests.
